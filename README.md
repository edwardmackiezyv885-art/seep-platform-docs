# SEEP — 多链数字资产质押与借贷

SEEP 是一个多链数字资产管理平台，提供**质押（Earn）**与**借贷（Borrow）**两类服务。用户通过浏览器钱包连接网络后直接使用，无需邮箱注册。

## 一、支持的网络与资产

| 网络 | 类型 | 钱包接入 | 备注 |
|---|---|---|---|
| BSC | EVM | 浏览器扩展 / 移动端 DApp 浏览器 | 当前主要充值网络（BEP20） |
| ETH | EVM | 同上 | 支持 |
| BTC | 非 EVM | 只读地址查询 | 无写入路径，仅账面记录 |
| TRON | 非 EVM | — | 已下线，仅保留配置 |

质押池与借贷市场均覆盖 7 种资产：**USDT、USDC、DAI、BTC、ETH、BNB、SOL**。每种资产对应一个独立质押池与一个独立借贷市场，参数分别设定。

## 二、产品结构

### 质押（Earn）

| 类型 | 锁定期 | 赎回 | 手续费 |
|---|---|---|---|
| 活期 | 无 | 随时赎回 | 赎回本金的 1% |
| 定期 | 360 天 | 锁定期内不可提前赎回，到期后可领取或继续质押 | 同左 |

- 收益由系统每日统一结算，结算后生成「待领取」记录
- **收益需手动领取**，未领取部分不自动到账，也不参与计息（非复利）
- 收益参数由平台按市场情况设定并在产品页展示，属浮动参数

### 借贷（Borrow）

- 先存入抵押资产，再借出该市场的可用流动性
- 每个市场独立设定：抵押率、借款利率、清算阈值
- 抵押物价格下跌 → 抵押率上升 → 超过清算阈值即触发清算
- 补充抵押物或偿还部分借款可降低抵押率

## 三、结算与领取

```
每日 00:00  系统统一结算 → 生成待领取记录（仅记账，不转账）
用户操作     点击领取 → 收益进入可用余额
提现        提交申请 → 平台风控校验资金密码 → 链上转出
```

关键区别：**结算 ≠ 到账**。结算只记账，领取才发生实际划转。

## 四、技术概要

- 前端：单页应用（hash 路由），静态资源托管，配套 PWA manifest，可「添加到主屏幕」
- 钱包交互：注入式 provider（`window.ethereum` 类），签名在本地钱包完成，平台不接触私钥
- 后端接口（同源 `/api/v1/*`）：

| 能力 | 接口 |
|---|---|
| 钱包签名换会话 | `POST /api/v1/session` |
| 充值意图 / 提交 txHash | `GET /api/v1/deposit/intent`、`POST /api/v1/deposits` |
| 质押 / 赎回 | `POST /api/v1/staking/orders`、`POST /api/v1/staking/orders/{id}/redeem` |
| 结算领取 | `GET /api/v1/claims`、`POST /api/v1/claims` |
| 提现 | `POST /api/v1/withdrawals` |
| 借贷 | `POST /api/v1/lend/supply`、`/borrow`、`/{id}/close` |
| 团队与奖励 | `GET /api/v1/team/overview`、`/api/v1/team/rewards` |

- 所有业务请求携带 `Authorization: Bearer <token>`，token 由钱包签名换取；资金类操作另需资金密码二次校验

## 五、风险

- 数字资产价格波动，质押与借贷均可能损失本金
- 抵押物价格下跌可能触发清算，损失大于单纯价格下跌
- 流动性不足时可能无法及时赎回
- 不同司法辖区的监管政策存在变化风险

本仓库内容为技术文档，不构成投资建议，不构成任何收益承诺。

## 六、常见问题（摘要）

完整 25 条见 [docs/faq.md](docs/faq.md)。

**Q：需要注册账号吗？**
不需要。连接钱包即登录，地址即账户。

**Q：私钥会保存在平台吗？**
不会。签名在本地钱包完成，平台只接收签名结果与公开地址。任何索要助记词的页面都不是官方页面。

**Q：每天结算等于每天到账吗？**
不等于。结算只是生成待领取记录，需手动领取才进入余额。

**Q：活期可以随时赎回吗？**
可以，收取赎回本金 1% 的手续费。定期在锁定期内不可提前赎回。

**Q：抵押率不足会怎样？**
超过该市场的清算阈值即触发清算，抵押物被处置以偿还债务。
